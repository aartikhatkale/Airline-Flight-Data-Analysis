# Airline-Flight-Data-Analysis
Airline Flight Data Analysis is a Power BI project that analyzes airline flight data to identify trends and insights related to flight delays, airlines, routes, and overall flight performance. The interactive dashboard uses charts, cards, and slicers to present key information clearly and support data-driven decision-making.
# ✈️ Airline Flight Data Analysis

## 📌 Project Overview

Airline Flight Data Analysis is a Power BI data analytics project designed to analyze airline flight data and identify useful patterns and insights.

The project uses interactive dashboards and visualizations to understand flight-related information such as airlines, routes, flight durations, prices, and other available flight attributes.

The main goal of this project is to transform raw airline data into meaningful insights using **Power BI**.

---

## 🎯 Objectives

- Analyze airline flight data.
- Understand different airline performances.
- Analyze flight-related patterns and trends.
- Compare airlines using interactive visualizations.
- Identify useful insights from the dataset.
- Create an interactive and user-friendly Power BI dashboard.
- Present data in a simple and understandable visual format.

---

## 🛠️ Technologies Used

- **Power BI**
- **Power Query**
- **DAX**
- **Microsoft Excel / CSV**
- **Data Visualization**

---

## 📊 Dashboard Features

The Power BI dashboard contains interactive visuals such as:

- 📌 KPI Cards
- 📊 Clustered Column Chart
- 🥧 Pie Chart
- 🍩 Donut Chart
- 🎛️ Slicers
- 📈 Interactive Charts
- 🔎 Filters for data analysis

These visuals help users explore the airline data and understand important patterns easily.
